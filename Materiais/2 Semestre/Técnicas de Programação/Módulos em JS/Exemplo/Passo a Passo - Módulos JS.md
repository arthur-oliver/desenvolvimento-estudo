COMO CRIAR INTERAÇÃO ENTRE MÓDULOS EM JS



1. Criar um arquivo (módulo) - nome arquivo = nome módulo.
2. Abrir terminal: npm init (depois "enter" em tudo) - OBS: tem que ser o terminal cmd (não powershell).
3. Criar arquivo index.js: dentro de index pode criar o parâmetro (código) que quiser para utilizar em outro módulo.
4. Cria outra pasta e repete o processo - OBS: é melhor abir outra janela do VSCode para funcionar.
5. Abrir terminal: npm install "endereco/caminho\_modulo\_deseja\_importar"- OBS: tem que ser o terminal cmd (não powershell).
6. Para rodar: terminal: node index js - OBS: tem que ser o terminal cmd (não powershell).
