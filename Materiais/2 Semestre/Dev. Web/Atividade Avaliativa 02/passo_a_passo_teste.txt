PASSO A PASSO PARA RODAR E TESTAR A API

A API será executada com Node.js + Express e os testes das rotas
serão realizados utilizando o Thunder Client, extensão disponível
dentro do VS Code.


========================================================
1. INICIANDO A API
========================================================

1. Abra o projeto no Visual Studio Code.

2. Abra o terminal do VS Code:

   Terminal -> New Terminal

3. Certifique-se de que o terminal está na pasta onde está
   o arquivo index.js.

4. Inicialize o projeto Node.js:

   npm init -y

5. Instale o Express:

   npm install express

6. Inicie o servidor:

   node index.js

7. Se estiver tudo correto, aparecerá:

   Servidor rodando em http://localhost:3000

8. NÃO feche esse terminal.

   Ele ficará executando o servidor enquanto os testes forem
   realizados.


========================================================
2. TESTANDO A API COM O THUNDER CLIENT
========================================================

Os testes serão realizados utilizando o Thunder Client,
dentro do próprio VS Code.

1. No VS Code, clique no ícone do Thunder Client na barra lateral.

2. Clique em New Request.

3. Para cada teste, selecione o método HTTP correspondente,
   informe a URL e clique em Send.

URL base:

http://localhost:3000


========================================================
3. CRIANDO A ORDEM 001
========================================================

Método:

POST

URL:

http://localhost:3000/ordens

Em:

Body -> JSON

insira:

{
  "codigoOrdem": "001",
  "codigoProduto": "PROD01",
  "tipoProduto": 1,
  "quantidadeProduzida": 1000,
  "custoUnitarioBase": 10,
  "estoqueInicial": 2000
}

Clique em Send.

Dados utilizados:

codigoOrdem = 001
codigoProduto = PROD01
tipoProduto = 1
quantidadeProduzida = 1000
custoUnitarioBase = 10
estoqueInicial = 2000

Resultado esperado:

estoqueFinal = 3000
custoUnitarioAjustado = 10
custoTotal = 10000
alertaEstoque = NORMAL

6. CONSULTANDO TODAS AS ORDENS
========================================================

Método:

GET

URL:

http://localhost:3000/ordens

Clique em Send.

001
002
003


========================================================
7. BUSCANDO UMA ORDEM ESPECÍFICA
========================================================

Para buscar a ordem 001:

Método:

GET

URL:

http://localhost:3000/ordens/001

Clique em Send.

A API deverá retornar somente os dados da ordem 001.


========================================================
8. FILTRANDO POR TIPO DE PRODUTO
========================================================

Para visualizar somente produtos do tipo 2:

Método:

GET

URL:

http://localhost:3000/ordens?tipo=2

Clique em Send.

O resultado deverá apresentar somente as ordens que possuem:

tipoProduto = 2


========================================================
9. FILTRANDO POR ALERTA DE ESTOQUE
========================================================

Para visualizar somente ordens com estoque ALTO:

Método:

GET

URL:

http://localhost:3000/ordens?alerta=ALTO

Clique em Send.

O resultado deverá apresentar as ordens cujo alerta de estoque
seja:

ALTO


========================================================
10. ATUALIZANDO UMA ORDEM
========================================================

Para alterar a quantidade produzida da ordem 001:

Método:

PUT

URL:

http://localhost:3000/ordens/001

Em:

Body -> JSON

insira:

{
  "quantidadeProduzida": 2000
}

Clique em Send.

A API deverá atualizar a quantidade e recalcular automaticamente:

estoqueFinal
custoUnitarioAjustado
custoTotal
alertaEstoque


========================================================
11. EXCLUINDO UMA ORDEM
========================================================

Para excluir a ordem 003:

Método:

DELETE

URL:

http://localhost:3000/ordens/003

Clique em Send.

A ordem 003 deverá ser removida.

Para confirmar, faça novamente:

Método:

GET

URL:

http://localhost:3000/ordens

A ordem 003 não deverá mais aparecer.


========================================================
12. CONSULTANDO O RELATÓRIO
========================================================

Para visualizar o relatório geral:

Método:

GET

URL:

http://localhost:3000/relatorios/ordens

Clique em Send.

O relatório deverá apresentar informações consolidadas
das ordens cadastradas, incluindo:

totalOrdens
estoquePorTipo
mediaCustoTotalPorOrdem
ordemMaisCara
ordemMaisBarata
quantidadeAlertas
porProduto

A ordem 003, que foi excluída anteriormente, não deverá
ser considerada no relatório.


========================================================
13. PARANDO O SERVIDOR
========================================================

Para encerrar o servidor, volte ao terminal do VS Code onde
o comando:

node index.js

está sendo executado.

Pressione:

Ctrl + C


========================================================
OBSERVAÇÃO
========================================================

As ordens são armazenadas somente na memória da aplicação.

Se o servidor for encerrado e iniciado novamente, todas as
ordens cadastradas serão apagadas.

Os testes da API são realizados utilizando o Thunder Client,
dentro do próprio Visual Studio Code.
